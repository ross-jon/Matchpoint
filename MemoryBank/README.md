# Memory Bank

This directory contains the core data store and supporting files for the
Memory Bank feature. The structure follows the standard project layout:

```
MemoryBank/
├─ data/          # Raw data files (JSON, CSV, etc.)
├─ config.json    # Configuration for the memory bank
├─ scripts/       # Utility scripts (e.g., import/export, migration)
└─ docs/          # Documentation and schema descriptions
```

Feel free to extend the structure as needed.
