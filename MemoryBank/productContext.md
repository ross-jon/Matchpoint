# Product Context

**MatchPoint** is a local competitive tennis flex ladder application. It
provides a mobile‑first experience for players to discover, challenge, and
report matches while maintaining a dynamic Elo‑based ranking system.

## Core Views
1. **Feed** – A chronological stream of completed matches with score
   summaries, Elo changes, and location tags.
2. **Ladder** – A leaderboard ranking all active players by Elo, with
   streak indicators and a filter for inactive users.
3. **My Matches** – A personal list of pending, accepted, completed, and
   verified matches, including the 24‑hour collaborative reporting window.

## Onboarding
During account creation users must check a **Code of Conduct** box that
verifies acceptance of the Strict Co‑Ed Professionalism Rule. Failure to
accept results in an immediate lifetime ban.

## Match Reporting Window
After a match passes its scheduled time, a 24‑hour window opens during
which either player may edit the set scores. The first player to approve
locks the scores, or the system automatically locks them when the timer
expires.
